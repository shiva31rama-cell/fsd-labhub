# User authentication

Login with demo-only credentials `admin` / `1234`, open `/profile`, then `/logout`. This intentionally simplified exercise is not production authentication. Production systems need password hashing, rate limiting, secure HTTPS cookies and a persistent session store.

## Run

```bash
npm install
npm start
```

Open http://localhost:3000. This is an educational lab exercise. Review the source comments and expected behavior before your practical exam.
