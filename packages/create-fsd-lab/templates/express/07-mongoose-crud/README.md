# Mongoose CRUD

Set `MONGODB_URI` in `.env` (or use the local default), start MongoDB, then use POST/GET/PUT/DELETE `/students`. Never commit real connection strings.

## Run

```bash
npm install
npm start
```

Open http://localhost:3000. This is an educational lab exercise. Review the source comments and expected behavior before your practical exam.

For MongoDB, configure `MONGODB_URI` in a local `.env` file. Do not commit credentials. See `.env.example`.
