# MongoDB document CRUD

Practise insert, find, update and remove operations on a students collection.

## Run
1. Start MongoDB Community Server or connect to Atlas using mongosh.
2. Execute `queries.mongodb.js` statement by statement.

The syllabus lists legacy `insert()`, `update()` and `remove()` methods. Modern mongosh uses `insertOne/insertMany`, `updateOne/updateMany` and `deleteOne/deleteMany`. Both forms are referenced in the file.
